# Bookworm

Rede social de leituras com feed, descoberta, progresso por página/porcentagem, biblioteca e perfil.

## Integrações

- Supabase: autenticação, PostgreSQL e Storage para avatares.
- Google Books/Open Library: catálogo amplo de livros (conexão prevista na próxima etapa).
- GitHub + Netlify: versionamento e publicação contínua.

Copie `.env.example` para `.env.local`, informe as chaves públicas do Supabase e aplique a migration de `supabase/migrations`.
